## 🔗 Связанные задачи  
Добавьте ссылки на задачи в системе управления проектами Jira (задач связанных может оказаться несколько)

_Пример:_

[JIRA-1234](https://jira.example.com/browse/JIRA-1234)   

## 🚀 Внесенные изменения  
Опишите ключевые моменты MR в рамках изменения по кодовой базе:  
- Изменения в моделях 
- Изменения в сущностях
- Изменения в тестах
- Изменения в API  
- Оптимизация кода  
- Новый функционал

Всё это можно перечислять как список из `"файл" - короткое объяснение`:
- `.gitlab/merge_request_templates/Default.md` - Добавлен шаблон для merge request

## 🎯 **Чек-лист** 
Все пункты чек листа заполняет ревьювер. Если его нет, то отметь самостоятельно то, что фактически соответствует.

Не отмеченные пару пунктов - это не критично. Вполне возможно, что в твоём коде на МР нету таких вещей, а значит необязательно отмечать.

### 📌 1. Общие требования  
- [ ] Код соответствует Style Guide (общий стиль проекта)
- [ ] Нет закомментированного кода, который не нужен

➖ **Опциональные пункты** 
- [ ] Нет временного кода (`TODO`, `print()`)
- [ ] Соответствует Code Design (с архитектурной точки зрения используются верные сущности)
- [ ] Обновление зависимостей пакетов

### 🧪 2. Тестирование  
- [ ] Добавлены тесты для новых функций и изменений

### 🔄 3. API и документация
- [ ] Приложены **скриншоты из Swagger** (если менялось API)

### ✍️ 4. Логирование
- [ ] Логирование ошибок и исключений
